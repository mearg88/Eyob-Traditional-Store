 ALREADY DECIDED (for the record - no action needed)
================================================================================

  * ARCHITECTURE: Plain React + Vite. No Next.js. One codebase for web and
    mobile, wrapped by Capacitor, deployed static to Vercel.
    NOTE: I will add a small crawler-detection function so WhatsApp/Facebook
    link previews still show the product photo and price. Roughly 60 lines,
    stays on the free tier.

  * INVENTORY: Mixed - some ready-made stock, some made to order. Stock
    tracking is the base for every product, with a "made to order" toggle
    that adds a lead time and an "in production" order status.
